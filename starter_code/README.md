# Agentic AI - Build Your Own AI Agent 🚀

Welcome to AgentForge!

Build your first AI agent using Python and Google's Gemini API.

## What you will learn

- Understand AI agents and LLMs.
- Connect an LLM using an API.
- Create Python tools.
- Give your agent a role and instructions.
- Build and test your own AI agent.

## Getting Started

### 1. Download the project

Click the green Code button and select Download ZIP.

Extract the downloaded folder.

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Configure your API key

Set your GEMINI_API_KEY environment variable or create a local `.env` file using `.env.example`.

### 4. Test your setup

```bash
python hello.py
```

### 5. Build your agent

Open `starter_code/agent.py`.

Change only the sections marked TODO.

### 6. Run your agent

```bash
python starter_code/agent.py
```

## Rules

- Change only TODO sections in the starter file.
- Never upload your API key.
- Test your agent before submission.
- Be creative and build something useful!
